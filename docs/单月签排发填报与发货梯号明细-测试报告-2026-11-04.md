## 四、关键链路实测

### 4.1 角色与按钮（P 组，22/22）
- 管理员：全量 + 导入 + 解锁，无每日实发入口；管理员即使有归属仍进入全量页。
- 查看上传/仅查看：全量只读，无导入、无实发。
- 单月填报角色：进入填报页，只能操作本人模块。
- 发货实发角色：全量 + 每日实发，无导入。
- 仅 `ship_tracking_admin`：可导入/解锁，无每日实发。
- 无权限、停用账号：context/登录被拒；越权写接口 403；实发缺密码 400。

### 4.2 单月填报（MF 组）
- 保存草稿：`mf_monthly_input` 1 行、`mf_ship_selection` 2 行；台数/金额取台账快照，前端篡改无效。
- 无效梯号：返回 `rejected`，有效行照常保存。
- 提交：状态 `submitted`、版本 v1、payload 含 11 指标 + 选梯明细；再次提交 v2，v1 快照不变。
- 手工添加返回码：EMPTY / NOT_FOUND / DUPLICATE / OTHER_MODULE 均按预期。
- 名单：读取、新增、重复拒绝、移除自身归属后保存 403 均符合预期。

### 4.3 发货明细（SI 组，65/65）
- 汇总卡片与列表一致；五状态之和等于总数；状态多选为「或」。
- 导出：16 列、大区第一、模块第二；表头 `172554`、行高 32、白字；斑马纹 `F5F9FF` 覆盖全部正文行；关闭网格线；`auto_filter=A1:P{max_row}`；文件名含「发货梯号明细」；导出范围跟随筛选。
- 周填报：草稿 → 提交 → 同周改期 → 同周撤回，字段变化全部正确；提交后清空草稿、候选池隐藏。
- 每日实发：错误密码、未来日期、历史无原因、当日二次无原因、跨日修改均被拒；正常录入、计划外实发、管理员作废均正确落库。
- 导入：预览不改主表；强制提交生成新版本、旧批次 superseded、快照保留；同一文件再次预览标记重复，不强制提交 400；同一批次重复提交 400；重导不清除实发/订舱事实。
- 详情：`/history` 返回审计列表；空梯号 400。

### 4.4 跨模块联动（X 组，9/9）
- 单月提交 → 从单月生成预览 → 提交：新增行 `source_kind=plan` 且无预计日期；只保存草稿的模块不参与；重复生成跳过已存在梯号。
- 台账同步只更新台账日期，不改预计/承诺/实发/订舱。

### 4.5 数据与隔离（DB 组，6/6）
- 发货模块写操作只改 `st_*`，审计 +1。
- 单月写操作只改 `mf_*`，`st_*` 行数不变。
- 副本 `PRAGMA integrity_check=ok`。
- 正式库中不存在 `QA-%` 账号，确认测试未写入正式库。
