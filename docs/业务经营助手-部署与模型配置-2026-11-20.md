# 业务经营助手部署与模型配置

日期：2026-11-20

## 1. 当前结构

经营助手采用“受控 Chatbot 编排”：

- 模型负责理解问题、识别模块、选择只读工具，以及把工具结果整理成自然语言。
- 后端负责权限过滤、数据查询、金额计算、表名清单和最终事实。
- 模型不连接数据库、不生成或执行 SQL，也不允许自行计算金额。
- 单次请求最多选择 3 个只读工具，支持复合问题和上下文追问。

## 2. 模型配置

后端启动时会尝试读取以下任一文件：

- `backend/.assistant.env`
- 项目根目录 `.assistant.env`

生产环境必须使用 `.assistant.env` 保存 API Key，不要写入前端、代码或 Git。

示例：

```ini
ASSISTANT_ENABLED=1
ASSISTANT_MODEL_ENABLED=1
ASSISTANT_MODEL_BASE_URL=https://api.deepseek.com
ASSISTANT_MODEL_API_KEY=替换为服务端密钥
ASSISTANT_MODEL_NAME=deepseek-chat
ASSISTANT_MODEL_TIMEOUT=25
ASSISTANT_MODEL_ANSWER_ENABLED=1
```

说明：

- `ASSISTANT_MODEL_ANSWER_ENABLED=1`：允许模型整理工具结果；设为 `0` 时只保留固定模板答复。
- `ASSISTANT_MODEL_TIMEOUT`：单次模型调用超时，建议 20 到 30 秒。
- 修改 `.assistant.env` 后必须重启后端进程，配置不会热加载。

## 3. 服务器更新步骤

1. 更新后端和前端代码。
2. 确认 `.assistant.env` 文件存在且权限仅限服务账号读取。
3. 重启后端服务。启动时会自动补充 `ba_setting`、`ba_conversation`、`ba_message`、`ba_query_log` 表，不需要手工迁移。
4. 如果前端有变化，执行 `cd frontend` 后运行 `npm run build`，并部署新的 `frontend/dist`。
5. 重启后登录管理员账号，进入“管理员 → 经营助手”。

## 4. 管理员验收

1. “模型配置”卡片应显示已配置、模型名称、接口地址、答复整理状态和超时。
2. 点击“测试模型连接”。测试会先验证意图识别，再验证答复整理。
3. 查询日志中应能看到实际请求：
   - `intent_source=model`：模型完成意图识别。
   - `intent_source=rule_fallback`：模型调用失败或输出无效，已回退固定规则。
   - `answer_source=model`：模型完成答复整理。
   - `answer_source=template`：答复使用后端固定文本。
4. 管理员可以直接问“合同 某合同号 回款多少”，再追问“这些数据从哪张表读取”。两轮都应返回结果，不被误判为业务外问题。

## 5. 安全边界

- 模型只接收当前登录用户权限范围内的工具结果摘要，不接收数据库连接信息或 API Key。
- 模型输出会校验数字和表名，只能使用工具结果中已经存在的事实。
- 如果模型新增数字、未知表名、返回非法 JSON、超时或接口报错，自动退回固定答复。
- 业务人员和普通角色的模块范围仍由 `mf_user_scope` 在后端计算，模型不能扩大权限。
- 助手仍是只读的，不执行保存、提交、撤回、改期或删除。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 模型配置显示“未启用” | 检查 `ASSISTANT_MODEL_ENABLED=1`，并重启后端。 |
| 显示“配置不完整” | 检查 `ASSISTANT_MODEL_API_KEY` 和 `ASSISTANT_MODEL_BASE_URL`。 |
| 测试返回 `http_401` | API Key 无效或已过期。 |
| 测试返回 `network_error` | 服务器无法访问模型接口，检查 DNS、代理和防火墙。 |
| 测试返回 `unexpected_action` | 模型可用，但路由输出与预期不一致，检查模型名称或提示词兼容性。 |
| 测试返回 `answer_check_failed` | 意图识别可用，但答复整理没有通过格式或事实校验。 |
| 日志中 `answer_source=template` | 答复已安全回退，查看 `answer_fallback_code`。 |

如需暂时只使用固定答复，将 `ASSISTANT_MODEL_ANSWER_ENABLED=0` 后重启后端。
