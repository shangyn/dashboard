# 单月签排发填报 - 2026 未排产候选池变更说明

变更日期：2026-11-18

## 1. 候选池规则

现有候选保持不变：

- `source = 'ledger'`
- `product_status` 为空或不等于 `已作废`
- `delivery_date` 为空（组A日期为空）
- 模块归属匹配当前填报模块
- `whole_ship_date` 为空或不晚于填报月份
- `schedule_date` 不为空（已排产）

本次新增：

- `schedule_date` 为空，且 `sign_date >= 2026-01-01`、`sign_date < 2027-01-01`

即：2026 年签订、尚未排产、尚未发货的合同也进入候选池。历史未排产合同不进入。

## 2. 页面标识与筛选

- 候选区标题改为“发货候选（组A日期为空；已排产，或 2026 年签订未排产）”。
- 排产日期为空的行在“排产日期”列显示“未排产”标签。
- 候选区增加排产状态筛选：全部梯号 / 已排产 / 未排产，默认“已排产”。
- 数量显示为当前筛选结果数，并展示全量已排产/未排产数量。

## 3. 数据参考

按 2026-11-12 本地库快照、填报月 2026-12 测算：

- 现有候选：1,770 条，345 个合同号
- 新增 2026 未排产：7,252 条，575 个合同号
- 合并：9,022 条，893 个合同号

新增部分产品状态构成：

- `未履行`：7,015 条
- `未排产`：237 条

## 4. 回滚方式

代码回滚只需把 `backend/monthly_forecast/services.py` 的排产条件恢复为：

`schedule_date IS NOT NULL`

前端标签和筛选可保留，也可一并移除。

注意：回滚不会自动清除已保存到 `mf_ship_selection` 的未排产勾选，也不会修改历史 `mf_submission` 快照。回滚前需检查是否已有用户保存或提交过新增候选。
